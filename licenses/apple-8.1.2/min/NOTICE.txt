FFmpeg n8.1.2 (https://github.com/arthenica/FFmpeg/tree/n8.1.2, the same tag as
the official n8.1.2 release), built as shared libraries with --enable-version3
and no GPL components, so it is licensed LGPL-3.0-or-later. See FFmpeg/.
FFmpeg contains no functional source modifications. The build scripts make two
build-system edits, to configure (stop adding -mdynamic-no-pic to assembler
flags) and ffbuild/common.mak (link the libraries as frameworks). See
patches/ffmpeg-n8.1.2-apple.patch. ${FFMPEG_LIBRARY_PATH} in that patch is the
build's install directory.
FFmpegKit (the libffmpegkit native wrapper and the build scripts) is licensed
LGPL-3.0. See ffmpeg-kit/LICENSE.

Corresponding source: https://github.com/sk3llo/ffmpeg-kit/tree/android-apple-8.1.2
(commit 984fa2d). FFmpeg source modifications made by the build scripts are in
patches/, as a unified diff against n8.1.2.

Build: SUDO= ./build-all.sh ios min and SUDO= ./build-all.sh macos min, with the
iOS 18.5 and macOS 15.5 SDKs. Minimum deployment targets: iOS 12.1, macOS 10.15.

Bundled third-party code: none. zlib, libc++, VideoToolbox, AVFoundation,
CoreVideo and the other frameworks used are provided by the operating system.
